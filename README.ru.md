# Сохранить WebP как PNG (расширение для Chrome)

[English](README.md) · **Русский**

Пункт **«Сохранить как PNG»** в контекстном меню (ПКМ) любой картинки. Интерфейс на русском или английском, в зависимости от языка Chrome. Файл сразу уходит
в папку загрузок Chrome (ту, что выбрана в `chrome://settings/downloads`). Если там включено
«Всегда указывать место для скачивания», Chrome спросит, куда сохранить.

## Установка

**Из релиза (без магазина):** скачайте `save-webp-as-png-<версия>.zip` со страницы
[Releases](https://github.com/P4ULdmit/save-webp-as-png/releases/latest) и распакуйте в папку, которую не будете удалять. Затем:

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (переключатель справа вверху).
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку (или папку этого репозитория).

После правок в коде нажмите ⟳ на карточке расширения.

## Что умеет

- **Без потерь.** Пиксели не проходят через 2D canvas, где альфа премультиплицируется и
  портит цвет полупрозрачных пикселей. Картинка декодируется с `premultiplyAlpha: 'none'`,
  загружается в текстуру WebGL2 и считывается бит-в-бит. Сохраняется даже RGB
  полностью прозрачных пикселей.
- **Альфа-канал.** Если в картинке нет прозрачных пикселей, PNG пишется как RGB: пиксели те же,
  файл меньше.
- **Цвет.** Если в исходнике есть ICC-профиль (WebP, PNG, JPEG), он без изменений переносится
  в PNG (чанк `iCCP`), а пиксели не конвертируются. Если профиля нет, PNG помечается как sRGB.
- **Скорость.** Собственный PNG-энкодер: адаптивный выбор фильтра для каждой строки (как в libpng),
  фильтрация в нескольких воркерах параллельно, сжатие нативным zlib браузера
  (`CompressionStream`). Картинки больше 4096 px обрабатываются тайлами.
- **Сложные сайты.** Картинка скачивается расширением с Referer страницы, так что CDN
  с защитой от хотлинка её отдают. Если так не вышло (`blob:`-ссылки, картинки за авторизацией),
  она скачивается изнутри страницы.
- Работает с любым форматом, который понимает Chrome: WebP, AVIF, JPEG, GIF, BMP, ICO, SVG.
- Имя файла берётся из URL или из `Content-Disposition`, расширение меняется на `.png`.
  Если такой файл уже есть, Chrome добавит к имени номер.

## Ограничения

- У анимированных WebP/GIF сохраняется только первый кадр.
- Фоновые CSS-картинки (`background-image`) в меню «изображение» не попадают. Это ограничение Chrome.
- Глубина цвета 8 бит на канал. Для WebP этого достаточно: он всегда 8-битный.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Manifest V3 |
| `_locales/en`, `_locales/ru` | Строки интерфейса (по умолчанию английский) |
| `background.js` | Контекстное меню, Referer, запасная загрузка через страницу, скачивание |
| `offscreen.html/js` | Offscreen-документ: загрузка → конвертация → blob URL |
| `lib/decode.js` | Точное декодирование в RGBA без премультипликации (WebGL2, тайлы) |
| `lib/png.js` | PNG-энкодер (IHDR / iCCP·sRGB / IDAT / IEND, CRC32, пул воркеров) |
| `lib/filter.js`, `lib/filter-worker.js` | Адаптивная фильтрация строк PNG |
| `lib/icc.js` | Извлечение ICC-профиля из WebP / PNG / JPEG |
| `store/` | Тексты для Chrome Web Store, политика конфиденциальности, скриншоты, [инструкция по публикации](store/PUBLISHING.md) |
| `pack.py` | Собирает ZIP для магазина в `dist/` |
