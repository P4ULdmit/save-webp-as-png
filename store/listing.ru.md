# Карточка в магазине — русский

Вставьте в панель разработчика Chrome Web Store → **Store listing**, выбрав язык «Русский».

**Название** (берётся из манифеста): Сохранить WebP как PNG

**Краткое описание** (берётся из манифеста, до 132 символов):
Сохраняет WebP (и любые другие картинки) в PNG из контекстного меню — без потерь, с прозрачностью и цветовым профилем.

**Категория:** Tools (Инструменты)

## Описание

Щёлкните правой кнопкой по картинке → «Сохранить как PNG». Файл сразу попадёт в папку «Загрузки» (или ту, которую вы выбрали в Chrome для скачивания). Без сайтов-конвертеров и лишних окон.

Сделано для WebP, но работает с любыми картинками, которые открывает Chrome: WebP, AVIF, JPEG, GIF, BMP, ICO, SVG.

ЧЕМ ОТЛИЧАЕТСЯ
Большинство конвертеров сначала рисуют картинку на canvas. Из-за этого незаметно меняется цвет полупрозрачных пикселей. Расширение берёт пиксели напрямую после декодирования, поэтому в PNG пиксели ровно те же, что в оригинале.

★ Без потерь: каждый пиксель сохраняется бит в бит, включая полупрозрачные
★ Полный альфа-канал: прозрачность сохраняется, а непрозрачные картинки пишутся в более компактный RGB PNG
★ Точные цвета: встроенный ICC-профиль переносится в PNG
★ Быстро: многопоточный PNG-энкодер, большие картинки обрабатываются по частям
★ Работает на капризных сайтах: справляется с CDN с защитой от хотлинка, blob:-картинками и картинками за авторизацией
★ Сохраняет исходное имя файла, только с .png
★ Интерфейс на русском и английском

КОНФИДЕНЦИАЛЬНОСТЬ
Всё происходит локально в вашем браузере. Картинки, адреса и личные данные никуда не отправляются. Никакой аналитики, рекламы и аккаунтов.

Ограничения: у анимированных картинок сохраняется первый кадр. Для фоновых CSS-картинок Chrome не показывает меню изображения.
